# Projeto de Exercícios em Python

Este projeto é uma coleção de exercícios básicos desenvolvidos em **Python**, com o objetivo de praticar e compreender conceitos fundamentais de programação. Os exercícios abordam temas como exibição de informações, entrada de dados pelo usuário e realização de operações matemáticas.


## Funcionalidades

* **Exercícios de programação:** conjunto de atividades para praticar conceitos básicos de Python.
* **Entrada e saída de dados:** utilização das funções `input()` e `print()` para interação com o usuário.
* **Operações matemáticas:** realização de cálculos e operações aritméticas.
* **Ambiente interativo:** os exercícios podem ser executados diretamente pelo o GoogleColab.
* **Fácil configuração:** o projeto utiliza principalmente recursos nativos do Python, não exigindo diversas dependências externas.

## Tecnologia utilizada

* **Python:** linguagem de programação utilizada no desenvolvimento dos exercícios.
